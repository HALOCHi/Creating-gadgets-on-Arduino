
### 🎵 **Новый компонент: Пьезодинамик (Зуммер)**

**📌 Что это такое?**
Это маленькая "пищалка", которая превращает электрические сигналы в звук. Внутри — специальный кристалл (пьезоэлемент), который вибрирует, когда на него подают напряжение.

**🔧 Особенности:**
*   **Пассивный зуммер** — просто пищит при подаче напряжения. Подключается как светодиод.
*   **Активный зуммер** — уже имеет встроенный генератор и пищит на одной частоте при подаче питания.
*   Для наших проектов лучше использовать **пассивный** — им можно управлять и менять тон!

**🔌 Как подключить:**
Подключить проще простого — как светодиод, но **БЕЗ резистора!**
```
    ПЬЕЗОДИНАМИК           ARDUINO
    ----------------       -------
    |              |       |     |
    |  Красный (+) |------>| D8  |
    |              |       |     |
    |  Чёрный (-)  |------>| GND |
    ----------------       -------
```
*   Полярность важна: обычно красный провод — "+", чёрный — "-"
*   Можно подключать напрямую к цифровому пину — ток потребления маленький

**💻 Базовый код для проверки:**

```cpp
#define buzzerPin 8 // Пин, к которому подключен зуммер

void setup() {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  // Просто пищим
  digitalWrite(buzzerPin, HIGH);
  delay(500); // Ждём 500 мс
  digitalWrite(buzzerPin, LOW);
  delay(500); // Пауза 500 мс
  
  // Или используем tone() для управления частотой
  tone(buzzerPin, 1000); // Пищим на частоте 1000 Гц
  delay(500);
  noTone(buzzerPin); // Выключаем звук
  delay(500);
}
```

**🎹 Две главные команды для звука:**
1.  `tone(pin, frequency)` — включает звук на указанном пине с заданной частотой (в Герцах). Чем выше частота, тем тоньше звук.
2.  `noTone(pin)` — выключает звук на этом пине.

**🔊 Частоты разных нот (для мелодий):**
```
До (C)  - 262 Гц
Ре (D)  - 294 Гц
Ми (E)  - 330 Гц
Фа (F)  - 349 Гц
Соль (G)- 392 Гц
Ля (A)  - 440 Гц
Си (B)  - 494 Гц
До2 (C2)- 523 Гц
```

---

### ⚠️ **Важные предупреждения:**

1.  **Не подключайте активный зуммер к ШИМ-пинам** с `tone()` — он может сгореть.
2.  **Если зуммер не пищит:** проверьте полярность, попробуйте другой пин, убедитесь, что он пассивный.
