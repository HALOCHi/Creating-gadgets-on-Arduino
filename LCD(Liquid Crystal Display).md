# **Дисплей LCD I2C**
1. Почему они до сих пор актуальны?

В эпоху графических OLED-экранов и сенсорных панелей простые алфавитно-цифровые (АЦ) дисплеи остаются востребованным решением. Их преимущества говорят сами за себя:

     - Минимальные требования к ресурсам микроконтроллера

     - Идеальная читаемость в любых условиях освещения

     - Простота управления и программирования

     - Низкая стоимость и доступность

     - Энергоэффективность для автономных устройств

Их можно встретить в системах умного дома, лабораторном оборудовании, торговых автоматах и сотнях других устройств, где важна чёткость, а не графика.
2. Разбираемся в маркировке

Каждый дисплей создаёт символы на матрице 5×8 точек, а его основные параметры закодированы прямо в названии модели.

Формат: ЧЧСС

    Первые две цифры — количество символов в строке

    Последние две цифры — количество строк



📌 Дополнительные опции:

    Цвет подсветки: синий (самый контрастный), зелёный, жёлтый, белый

    Тип отображения: светлые символы на тёмном или тёмные на светлом

Преимущества I2C-подхода:

    ✅ Всего 4 провода: VCC, GND, SDA, SCL

    ✅ Экономия пинов (освобождает 6-8 линий!)

    ✅ Встроенная регулировка контраста

    ✅ Чистая и понятная монтажная схема

Схема подключения:
```text
Arduino               LCD_I2C
5V            ->       VCC
GND           ->       GND
A4 (SDA)      ->       SDA
A5 (SCL)      ->       SCL
```

4. Когда выбирать такой дисплей?

✅ Идеально подходит для:

    Систем вывода числовых показаний (температура, влажность, напряжение)

    Меню настройки приборов

    Простых информационных панелей

    Учебных проектов и прототипирования

❌ Рассмотрите графический дисплей если нужно:

    Отображать графики и диаграммы

    Использовать несколько шрифтов одновременно

    Показывать анимацию или сложные элементы интерфейса

5. Базовая структура кода, чтобы проверить правильность сборки и немножечко плюсОв
   Перед компиляцией исходного файла программы выполняется препроцессинг - изменение текста программы. Его выполняет препроцессор - отдельная утилита, которая имеет свой набор команд для управления: все команды начинаются с символа #. По сути возможности препроцессора делают его отдельным языком программирования, при помощи которого можно генерировать код программы на C/C++.

   **#include**

Вставляет содержимое заголовочного файла, указанного в:

    "двойных кавычках" - искать файл сначала в текущей папке с исходником, затем в папке с библиотеками (пользовательскими и системными)
    <угловых скобках> - искать файл в папке с библиотеками

```cpp
#include "mylib.h"  // подключить mylib.h, сначала поискать в папке с проектом
#include <LiquidCrystal_I2C.h>  // подключить mylib.h из папки с библиотеками
```

**#define**

Команда #define позволяет буквально заменить в тексте программы указанный набор символов на другой набор символов. Синтаксис очень простой: ```#define A B - заменить A на B```:

    Точка с запятой не ставится, т.к. это не инструкция и не относится к синтаксису языка
    Между A и B должен быть как минимум один пробел, то есть больше - можно
    B может быть не указана - в этом случае A просто вырежется из кода


define-константы имеют глобальную область видимости - препроцессор заменяет указанный набор символов во всём исходном файле программы

Поэтому дефайн-константы принято называть в СТИЛЕ_КРИЧАЩЕЙ_ЗМЕИ (SCREAMING_SNAKE_CASE) и использовать префиксы модулей, например в своей библиотеке:
```cpp
#define MY_LIB_CONST1   10
#define MY_LIB_ADDRESS  0x85
#define MY_LIB_MODE0    0
#define MY_LIB_MODE1    1
```

## 📋 Базовый скетч для проверки сборки

```cpp
#include <LiquidCrystal_I2C.h> // Основная библиотека для дисплея

/*
 * Создаем объект дисплея с параметрами:
 * 0x27 - адрес I2C (может быть 0x3F, 0x20 или другим)
 * 16   - количество символов в строке
 * 2    - количество строк
 */
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  Serial.begin(9600);      // Инициализация Serial(консоли) для отладки
  
  lcd.init();              // Инициализация дисплея
  lcd.backlight();         // Включаем подсветку
  
  // Выводим приветственное сообщение
  lcd.print("LCD test");
  lcd.setCursor(0, 1);    // Переходим на вторую строку
  lcd.print("Try again");
  
  Serial.println("Если видишь текст на дисплее, то всё успешно!");

}

void loop() {
  // Мигаем подсветкой для визуальной проверки
  delay(2000);
  lcd.noBacklight();      // Выключаем подсветку
  delay(500);
  lcd.backlight();        // Включаем подсветку
}
```

## 📚 Основные функции библиотеки LiquidCrystal_I2C

### 1. **Инициализация и базовые команды**

```cpp
// Создание объекта
LiquidCrystal_I2C lcd(address, columns, rows);

// Инициализация дисплея (ВСЕГДА в setup!)
lcd.init();

// Управление подсветкой
lcd.backlight();      // Включить
lcd.noBacklight();    // Выключить
lcd.setBacklight(HIGH/LOW);  // Управление через состояние
```

### 2. **Управление курсором и позиционирование**

```cpp
// Очистка экрана
lcd.clear();

// Установка курсора (колонка, строка)
// Нумерация с 0! Для 16x2: колонки 0-15, строки 0-1
lcd.setCursor(0, 0);     // Первый символ первой строки
lcd.setCursor(15, 1);    // Последний символ второй строки

// Возврат курсора в начало
lcd.home();
```

### 3. **Вывод информации**

```cpp
// Вывод текста
lcd.print("Hello");           // Строка
lcd.print(123);               // Целое число
lcd.print(3.14);              // Дробное число
lcd.print(variable);          // Переменная

// Вывод отдельных символов
lcd.write('A');               // Символ
lcd.write(byte(0));           // Пользовательский символ
```

### 4. **Создание пользовательских символов**

```cpp
// Создаем массив из 8 байт (5x8 точек)
byte heart[8] = {
  0b00000,
  0b01010,
  0b11111,
  0b11111,
  0b01110,
  0b00100,
  0b00000,
  0b00000
};

void setup() {
  lcd.init();
  lcd.createChar(0, heart);  // Регистрируем символ под номером 0
  lcd.setCursor(0, 0);
  lcd.write(0);        // Выводим созданный символ
}
```

### 5. **Управление отображением**

```cpp
// Включить/выключить дисплей (сохраняет содержимое)
lcd.display();      // Показать
lcd.noDisplay();    // Скрыть

// Управление курсором
lcd.cursor();       // Показать курсор (_)
lcd.noCursor();     // Скрыть курсор

// Мигающий курсор
lcd.blink();        // Включить мигание
lcd.noBlink();      // Выключить мигание
```

### 6. **Прокрутка и движение**

```cpp
// Сдвиг содержимого дисплея
lcd.scrollDisplayLeft();   // Сдвиг влево
lcd.scrollDisplayRight();  // Сдвиг вправо

// Автопрокрутка текста
void scrollText(String message, int row) {
  lcd.setCursor(16, row);
  lcd.autoscroll();        // Включаем автопрокрутку
  lcd.print(message);
  delay(500);
  lcd.noAutoscroll();      // Выключаем автопрокрутку
}
```

## 🚨 Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Пустой экран | Неправильный адрес I2C | Используйте сканер I2C |
| Видны только квадраты | Проблема с контрастом | Настройте потенциометр на модуле |
| Текст размытый | Плохой контакт | Проверьте пайку/соединения |
| Не все символы видны | Сбита настройка контраста | Плавно регулируйте потенциометр |
