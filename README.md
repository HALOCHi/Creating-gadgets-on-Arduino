# Creating Gadgets on Arduino

[![License: CC BY-NC-SA 4.0](https://shields.io)](https://creativecommons.org)

Добро пожаловать в репозиторий **Creating-gadgets-on-Arduino**! Это структурированный пошаговый курс, посвященный проектированию, сборке и программированию автономных цифровых гаджетов на базе платформы Arduino.

---

## О проекте: Зачем, Кем и Для кого?

### Зачем создается этот проект?
Главная цель репозитория — предоставить **практические руководства** по сборке IOT-устройств, их программированию, изучению математических основ информатики и программирования. 
Вместо сплошной теории, которую вы можете найти на просторах интернета, здесь собран по большей степени прикладной материал (но материал не лишённый теории и определений, т.к. без них никуда)

### Кем он составляется?
Материалы курса разрабатываются и поддерживаются мной, [HALOCHi](https://github.com), на основе личного опыта работы программирования, в том числе микроконтроллеров, и преподавания. Проект открыт для улучшений со стороны сообщества через Pull Requests.

### Для кого этот курс?
* **Преподавателям робототехники и наставникам:** Подходит как готовый бесплатный методический план для кружков, школьных факультативов или домашних заданий.
* **Юным инженерам и школьникам:** По возможности материал пишется простым языком, чтобы при самостоятельном изучении не возникало сложностей (или возникало их как можно меньше). Для большей понятности репозиторий помогают улучшать сами ученики, кто работает с этим материалом.
